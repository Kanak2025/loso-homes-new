# LOSO Homes — website mock-up

    node server.js        # or: npm start
    open http://localhost:3000

Node 16+. All 14 product photos are local (media/01.jpg … 14.jpg); only Google Fonts needs internet.

Edit products  -> data.js (name, price, category, photo path)
Add a video    -> drop media/reel.mp4 (plays inside the Instagram-style phone on the home page)
Swap a photo   -> replace media/NN.jpg with a higher-resolution file of the same name

Names, prices, reviews and journal titles are placeholders.
